# Talking Head with B-roll

Thirty-second vertical spoken story alternating presenter footage with city and coffee B-roll. The voice remains authoritative while the music ducks dynamically; visual changes support sentence meaning rather than cutting on every beat.

The included demo voice is generated locally with FFmpeg's `flite` source so the audio pipeline can be reviewed without an external speech service.

```bash
npm run create -- --project projects/03-talking-head-broll
```

The rendered file is `output/03-talking-head-broll.mp4`.
