# City After Dark Stock Montage

Twenty-second vertical mood montage built from nine unique, reviewed, pinned Pexels clips. It does not claim to be one Seoul trip. The authored cut map changes scenes around large waves in the selected M83 excerpt at `4.0`, `6.25`, `8.75`, `12.25`, and `15.75` seconds without forcing routine beat alignment or automatic transition effects.

```bash
npm run create -- --project projects/01-cinematic-travel-reel
npm run evaluate -- --storyboard projects/01-cinematic-travel-reel/storyboard.json
```

Review `storyboard.json`, `beat-map.json`, all three quality sheets, and `sources/`. The rendered file is `output/01-cinematic-travel-reel.mp4`.
