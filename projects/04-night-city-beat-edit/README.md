# Tokyo Night Mood Montage

Twenty-two-and-a-half-second vertical stock montage using Tokyo night streets, crowds, signs, trains, traffic, and skyline views. The Nightcall excerpt preserves two complete lyric lines. Section changes and the skyline payoff follow large musical changes; ordinary beats remain secondary timing evidence.

```bash
npm run create -- --project projects/04-night-city-beat-edit
npm run evaluate -- --storyboard projects/04-night-city-beat-edit/storyboard.json
```

Transitions are hard cuts unless a project explicitly authors a footage-compatible transition accent. The rendered file is `output/04-night-city-beat-edit.mp4`.
